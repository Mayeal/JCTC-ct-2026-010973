**Directory Structure**

- opt-freq: Contains the input and output files for geometry optimization and frequency calculations. The built-in BDF script optgeom2xyz can be used to convert the output file filename.optgeom into an XYZ coordinate file.
- coordinates: Contains the coordinate files for all molecular structures used in this work.
- NACMEs: Input and output files for NACME calculations between the ground state and excited state (e.g., $\mathrm{^2T_1-^2S_0}$), as well as between excited states (e.g., гд\mathrm{^2T_1-^2dd_1}$), using the X-TDDFT method.
- scripts: Contains scripts for converting Hessian and NACME files generated by BDF into input files compatible with MOMAP.
- data.csv: Raw data used to calculate the adiabatic energies (Ead in momap.inp) according to Eq. 135 in the article.
