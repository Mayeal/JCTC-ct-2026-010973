**Directory Structure**

- opt-freq: Contains the input and output files for geometry optimization and frequency calculations. The built-in BDF script optgeom2xyz can be used to convert the output file filename.optgeom into an XYZ coordinate file.
- coordinates: Contains the coordinate files for all molecular structures used in this work.
- NACMEs: Contains input and output files for NACME calculations between the ground state and excited state (e.g., $\mathrm{^2T_1-^2S_0}$), as well as between excited states (e.g., $\mathrm{^2T_1-^2dd_1}$), using X-TDDFT.
          The data directory contains the NACMEs for all state pairs discussed in the manuscript.
- SOCMEs-Ead: Contains the output files used to extract the data (ISC-data.csv and FL-data.csv) required for ISC and fluorescence rate calculations.
- scripts: Contains scripts for converting Hessian and NACME files generated by BDF into input files compatible with MOMAP.
- IC-data.csv: Raw data used to calculate the adiabatic energies (Ead in momap.inp) according to Eq. 135 in the article.
