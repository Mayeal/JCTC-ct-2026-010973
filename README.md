# Data Repository for Analytic first-order non-adiabatic coupling matrix elements of spin-adapted open-shell time-dependent density functional theory
Preprint: http://arxiv.org/abs/2605.26594

## Overview
This repository provides the key computational files associated with the manuscript:
  
Analytic first-order non-adiabatic coupling matrix elements of spin-adapted open-shell time-dependent density functional theory 
 
The purpose of this repository is to facilitate the transparency and reproducibility of the calculations reported in the manuscript. 

The repository contains:
- Input files used in the calculations
- Output files generated by the calculations
- Raw data used to obtain the reported results
- Scripts used for data extraction, conversion, and analysis

These materials provide the data and computational details underlying the key results reported in the manuscript.
